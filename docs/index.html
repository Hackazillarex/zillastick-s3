Flash Firmware

Connect your M5Stack Stick S3 via USB, then click the button below.
No drivers or software to install — works directly in your browser.

Requires Chrome or Edge with Web Serial enabled. First flash will erase the device.

Before You Flash

  1. Use Chrome or Edge — Firefox does not support Web Serial.
  2. Connect via USB-C — use the port on the M5Stick S3 body, not the RF Pack.
  3. Hold BtnA while plugging in if the device is not detected — this puts it into download mode.
  4. Select the correct COM port when the browser prompts — it will be labeled CP210x or similar.
  5. After flashing, the device reboots automatically into the ZILLASTICK S3 menu.
⚠ First flash erases all saved data. WiFi credentials, captures, and payload files on the device will be wiped. Back up anything important first via the File Manager or Remote Ctrl Files tab.

Hardware Compatibility

This firmware is built specifically for the M5Stack Stick S3 with the Pingequa RF Pack S3 v1. Other hardware combinations are not supported.
